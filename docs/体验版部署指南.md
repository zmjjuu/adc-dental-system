# 微信小程序「体验版」部署指南

目标：让老师在手机上通过微信直接扫码使用小程序。全程约 1—2 小时（含等待部署时间）。

> 为什么用**微信云托管**：小程序体验版/正式版只能请求在公众平台后台配置过的「request 合法域名」，该域名必须 **HTTPS + ICP 备案**。海外免费服务器（Render/Vercel 等）的域名无法备案、加不进白名单。微信云托管是官方方案：域名自动免备案接入、按量计费、不用时可停服。

## 第 0 步：确认 AppID 是你本人的

1. 登录 https://mp.weixin.qq.com （用你注册小程序的微信扫码）
2. 首页左上角应显示你的小程序名称和 AppID
3. 确认 AppID 与 `miniprogram/project.config.json` 里的 `appid` 一致（当前为 `wx3ea95b4e106d2798`）
   - 如果不是你的 AppID：在 mp.weixin.qq.com 注册一个新的（个人主体即可，免费），再把 project.config.json 里的 appid 换掉

## 第 1 步：完善小程序信息（上传代码的前提）

mp.weixin.qq.com → 管理 → 基本设置 → 完善：

- **名称**：建议先试「安德鲁牙科连锁管理系统」；如果名称审核不通过（医疗类词汇对个人主体较敏感），改用中性名如「ADC 连锁管理系统」——名称不影响代码运行
- **头像 / 简介**：随意，介绍写"课程设计：牙科连锁门店管理系统演示"
- **服务类目**：选不涉医的类目，如 **工具 > 企业管理** 或 **教育 > 教育信息服务**（本系统是管理软件演示，不含诊疗功能；选医疗类目反而需要医疗机构资质）

## 第 2 步：开通微信云托管（有少量费用）

1. mp.weixin.qq.com → 开发 → **云开发（云托管）** → 开通（需完成微信支付实名认证）
2. 计费方式选**按量计费**（开通页如有新用户免费额度/试用先领取）
   - 最低配实例（0.25 核 / 0.5 GB）约 **¥0.06/小时 ≈ ¥1.4/天**，演示完在控制台点**「停服」**即停止计费
   - SQLite 直接跑在容器里，无需另购数据库；外网流量费可忽略

## 第 3 步：创建服务并部署后端

1. 云托管控制台 → **新建服务** → 服务名称随意（如 `adc`）→ 地域选离你近的
2. 部署方式选 **从代码仓库部署** → 授权并选择 GitHub 仓库 `zmjjuu/adc-dental-system`（仓库根目录已有 `Dockerfile`）
3. 构建配置：
   - 构建方式：Dockerfile
   - 监听端口：**80**（Dockerfile 里已 `ENV PORT=80`，app.py 会自动读取）
   - 实例数：**1**（SQLite 数据在单实例内，多实例会各自一套演示数据）
4. 点击部署，等待构建完成（几分钟）→ 状态变为「运行中」

## 第 4 步：拿到域名并加入小程序白名单

1. 云托管控制台 → 你的服务 → **服务设置/访问域名**：得到类似
   `https://adc-xxxxx-xxxxx.tcloudbaseapp.com` 的 HTTPS 域名
2. mp.weixin.qq.com → 开发 → 开发管理 → **开发设置 → 服务器域名 → request 合法域名** → 添加该域名（去掉 `https://` 前缀）
   - 云托管域名无需备案即可添加成功；如有「微信接入 / 一键配置域名」按钮可直接点

## 第 5 步：修改小程序 API 地址并验证

1. 修改 `miniprogram/utils/api.js` 第一行：
   ```js
   const BASE = 'https://adc-xxxxx-xxxxx.tcloudbaseapp.com';
   ```
2. 微信开发者工具重新编译 → 登录测试各功能正常（云上数据是全新的一套演示数据）
3. 确认无误后提交推送：`git add -A && git commit -m "小程序接入云托管域名" && git push`

## 第 6 步：上传体验版

1. 开发者工具右上角点击 **上传** → 版本号如 `1.0.0`、备注随意
2. mp.weixin.qq.com → 管理 → **版本管理** → 开发版本里找到刚上传的版本 → 点 **选为体验版**
3. 页面会生成**体验版二维码**（可下载发给老师，但老师必须先被加为体验成员）

## 第 7 步：把老师加为体验成员

1. mp.weixin.qq.com → 管理 → **成员管理 → 体验成员** → 添加 → 输入老师的**微信号**（不是昵称，需向老师询问）
2. 老师微信会收到「小程序体验邀请」，接受后扫体验版二维码即可使用
3. 登录用演示账号（如 `F-1001` / `123456`），老师和你可以同时在线操作同一套数据

## 日常使用与省钱

- **不演示时**：云托管控制台 → 服务 → **停服**（数据会随容器销毁重置为初始演示数据，重启后自动重新生成，不影响演示）
- **再次演示时**：控制台点启动 → 约 1 分钟恢复
- 更新代码：改完推送 GitHub → 云托管控制台「重新部署」（可配置为推代码自动构建）

## 常见问题

- **小程序打不开/白屏**：检查 ① 域名是否加了 request 合法域名 ② api.js 的 BASE 是否与云托管域名一致 ③ 服务是否「运行中」（没启动/已停服）
- **request 域名添加失败**：确认填的是纯域名（不带 https:// 和路径），云托管域名应可直接通过
- **上传按钮灰掉**：确认开发者工具登录的微信账号是这个小程序的**管理员或开发者**（成员管理里看角色）
- **老师扫码提示"无权限"**：老师未接受体验邀请，或加的是昵称而不是微信号
